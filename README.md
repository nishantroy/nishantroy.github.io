# nishantroy.github.io

Personal site. Static HTML and CSS, no build step and no dependencies.

- `index.html`: the page. All copy lives here.
- `styles.css`: the design. Colors are tokens on `:root` with a dark-mode set; the "After hours" bands each define their own.
- Fonts load from Google Fonts (Literata, Hanken Grotesk).

Preview locally by opening `index.html` in a browser. GitHub Pages serves the repository root.
