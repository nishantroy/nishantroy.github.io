# nishantroy.github.io

Personal site. Static HTML, CSS and a little JavaScript. No build step, no dependencies.

- `index.html`: the page. All copy lives here.
- `styles.css`: design tokens on `:root` (with a dark-mode set), layout, and the phone frame.
- `site.js`: the per-project screen switcher. The list of screens per project lives at the top.
- `assets/<project>/N.webp`: real app screenshots, 780px wide WebP (simulator captures for the iOS apps, Chrome device emulation for Bink City).

Preview locally by opening `index.html` in a browser. GitHub Pages serves the repository root when the repo is public.
